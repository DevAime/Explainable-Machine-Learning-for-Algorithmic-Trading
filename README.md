## Overview

This project investigates whether explainable AI (XAI) explanations improve
the quality of human trading decisions. A machine learning model is trained
to predict next-day price direction (Buy / Sell) on historical S&P 500 data.
The model's predictions are then explained using SHAP, and participants in a
controlled experiment make simulated trading decisions both with and without
those explanations.

The core research question is: **does showing a trader why an AI made a
recommendation help them make better decisions?**

## How It Works

### 1. Machine Learning Pipeline (`model.py`)

- Loads and cleans daily OHLCV data for SPY (S&P 500 ETF)
- Engineers 17 technical indicator features: SMA, EMA, RSI, MACD, Bollinger
  Bands, rolling volatility, and lagged returns
- Defines the target variable: 1 if next-day close > today's close (BUY), 0 otherwise
- Splits data chronologically — 70% train / 15% validation / 15% test
- Trains three models: Logistic Regression (baseline), Random Forest,
  and Gradient Boosting
- Selects the best model by ROC-AUC and computes SHAP values for all
  test-set predictions
- Exports the model, scaler, test results, and SHAP plots

### 2. Streamlit Web App (`app.py`)

The app serves as the experiment interface for study participants. It has
five pages:

| Page | Description |
|---|---|
| Home | Study overview and participant instructions |
| Trading Scenario | Price chart + model recommendation, no explanation (control condition) |
| With Explanation | Same scenario + SHAP bar chart and plain-English summary (treatment condition) |
| Decision Form | Participant records Buy/Hold/Sell, confidence rating, and comments |
| Results Dashboard | Researcher view — aggregated accuracy, confidence, and decision distribution |

## Getting Started

### Prerequisites

```bash
pip install pandas numpy scikit-learn xgboost shap matplotlib streamlit
```

### Run the pipeline first

```bash
python model.py
```

This generates `test_results.csv`, `best_model.pkl`, `scaler.pkl`,

```bash
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`.

## Data

Historical daily OHLCV data for SPY was downloaded using the `yfinance`
library covering January 2010 to December 2024 (~4,000 trading days).
The data is publicly available and requires no API key.

To re-download fresh data:

```python
import yfinance as yf
df = yf.download("SPY", start="2010-01-01", end="2024-12-31", auto_adjust=True)
df.columns = df.columns.get_level_values(0)
df.to_csv("spy_data.csv")
```

## Research Design

The human experiment follows a **within-subject design**: each participant
completes trading tasks under both the control condition (no explanation)
and the treatment condition (with SHAP explanation), with randomised order.
Outcomes measured include decision accuracy, confidence ratings, and
perceived trust in the AI system.

**Target participants:** 15–30 university students and early-career
professionals with basic financial familiarity.
